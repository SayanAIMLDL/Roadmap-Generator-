⚙️ METHODS/FUNCTIONS:
---------------------

1. render_markmap(markdown_content: str, height: int = 700):
   • Purpose: Render interactive mindmap using Markmap.js
   • Parameters: markdown_content (str), height (int)
   • Returns: None (renders HTML component)
   • Work:
     - Escapes markdown content for security (XSS prevention)
     - Creates HTML template with Markmap.js integration
     - Applies roadmap.sh-inspired styling and theming
     - Implements interactive features (collapsible nodes, zoom)
     - Handles responsive design and mobile compatibility
     - Uses streamlit.components.v1.html for rendering
   • Security: Input sanitization and XSS prevention
   • User Experience: Interactive, professional visualization

2. render_topic_details(topic_name: str, topic_content: Dict):
   • Purpose: Display comprehensive topic details with validation
   • Parameters: topic_name (str), topic_content (Dict)
   • Returns: None (renders Streamlit components)
   • Work:
     - Validates topic name using SecurityValidator
     - Creates tabbed interface (Guide, Resources, Details)
     - Displays description, key points, code examples
     - Shows verified learning resources with validation
     - Implements technical details view with JSON display
     - Handles errors gracefully with user-friendly messages
   • Security: Input validation and URL security checks
   • User Experience: Organized, professional content display

3. show_topic_details(topic_name: str, content: Dict):
   • Purpose: Enhanced topic display with interactive features
   • Parameters: topic_name (str), content (Dict)
   • Returns: None (renders Streamlit components)
   • Work:
     - Creates comprehensive tabbed interface
     - Displays learning content with code examples
     - Shows verified resources with source attribution
     - Implements "next steps" interactive feature
     - Handles form submissions for continued learning
     - Applies premium CSS styling for professional appearance
     - Manages session state for user interactions
   • Interactivity: Form-based navigation and state management
   • Security: Input validation and session security

4. show_topic_sidebar(roadmap_data: Dict, selected_topic_id: str):
   • Purpose: Display topic details in sidebar
   • Parameters: roadmap_data (Dict), selected_topic_id (str)
   • Returns: None (renders in sidebar)
   • Work:
     - Finds selected topic from roadmap structure
     - Retrieves content for selected module/subtopic
     - Displays comprehensive topic details in sidebar
     - Handles missing content gracefully
     - Integrates with main topic display function
   • User Experience: Convenient sidebar access to details
   • Performance: Efficient topic lookup and content retrieval

5. roadmap_page(llm):
   • Purpose: Main roadmap generation page interface
   • Parameters: llm (ChatGroq instance)
   • Returns: None (renders complete page)
   • Work:
     - Initializes roadmap and content generators
     - Creates input forms for query and context
     - Handles roadmap generation with progress indicators
     - Displays interactive mindmap visualization
     - Manages session state for user interactions
     - Implements content generation on demand
     - Handles "next steps" navigation and state updates
   • State Management: Comprehensive session handling
   • User Experience: Complete learning workflow
