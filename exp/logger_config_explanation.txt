⚙️ CLASSES/METHODS:
---------------------

1. ShifuLogger:
   • Purpose: Centralized logger with structured formatting
   • Design: Singleton pattern for application-wide consistency
   • Work: Provides logging methods with context support
   • Features: Multiple handlers, formatters, and filters
   • Security: No sensitive data in logs

2. __init__(self, name: str = "shifu"):
   • Purpose: Initialize logger with configuration
   • Parameters: name (str) - Logger name
   • Returns: ShifuLogger instance
   • Work:
     - Creates logger instance with specified name
     - Clears existing handlers to prevent duplicates
     - Sets log level from configuration
     - Configures formatters for structured output
     - Sets up console and file handlers
     - Creates log directory if needed
   • Security: No sensitive data in log format
   • Performance: Efficient handler setup

3. _setup_logger(self):
   • Purpose: Configure logger with handlers and formatters
   • Parameters: None (uses instance state)
   • Returns: None
   • Work:
     - Creates structured formatter with timestamps
     - Sets up console handler with colored output
     - Configures file handler with rotation
     - Applies log level filtering
     - Ensures proper error propagation
   • Performance: Optimized handler configuration
   • Maintainability: Clean separation of concerns

4. Structured Formatter:

     - Supports context data via kwargs
     - Separates context for easy parsing
