🗺️ ROADMAP_GENERATOR.PY - ROADMAP GENERATION ENGINE
===============================================

📚 LIBRARIES/MODULES USED:
---------------------------
• json - JSON parsing and serialization
• os - File system operations and path handling
• hashlib - MD5 hashing for caching and filenames
• datetime - Timestamp generation and metadata
• typing - Type hints (Dict, List, Optional)
• langchain_groq.ChatGroq - LLM integration for roadmap generation
• langchain_core.prompts.PromptTemplate - LLM prompt management
• config module - Secure configuration management
• logger_config module - Structured logging
• security module - Input validation and sanitization

🏗️ ARCHITECTURE & PURPOSE:
----------------------------
Generates personalized learning roadmaps using LLM with:
• Structured JSON generation from user queries
• Robust parsing with multiple fallback strategies
• Secure file operations with validation
• Caching system for performance optimization
• Markmap-compatible markdown output
• Comprehensive error handling and logging

⚙️ METHODS/FUNCTIONS:
---------------------

1. __init__(llm: ChatGroq, data_dir: str = None):
   • Purpose: Initialize roadmap generator with configuration
   • Parameters: llm (ChatGroq), data_dir (str, optional)
   • Returns: RoadmapGenerator instance
   • Work:
     - Sets up LLM instance for content generation
     - Configures data directory for roadmap storage
     - Creates necessary directories (roadmaps/, content_cache/)
     - Logs initialization with configuration details
   • Security: Path validation and directory creation
   • Performance: Pre-creates directory structure

2. ensure_directories():
   • Purpose: Create required directory structure
   • Parameters: None
   • Returns: None
   • Work:
     - Creates roadmap storage directory
     - Creates content cache directory
     - Uses exist_ok=True to prevent errors
     - Implements secure directory creation
   • Security: Safe directory creation with proper permissions

3. generate_roadmap_structure(query: str, user_context: str = ""):
   • Purpose: Generate roadmap structure using LLM
   • Parameters: query (str), user_context (str)
   • Returns: Dict with roadmap data and metadata
   • Work:
     - Validates and sanitizes user inputs
     - Creates detailed prompt for LLM
     - Invokes LLM for roadmap generation
     - Parses JSON response with robust error handling
     - Adds metadata (timestamps, query, context)
     - Implements fallback structure on failures
   • Security: Input validation and sanitization
   • Performance: Caching and efficient JSON parsing

4. _parse_llm_response(response_text: str, query: str):
   • Purpose: Parse LLM response with robust error handling
   • Parameters: response_text (str), query (str)
   • Returns: Dict (roadmap structure)
   • Work:
     - Cleans response text (removes markdown blocks)
     - Finds JSON object boundaries
     - Attempts direct JSON parsing
     - Fixes common JSON issues (trailing commas)
     - Implements fallback structure on parsing failures
     - Logs parsing attempts and results
   • Error Handling: Multiple fallback strategies
   • Performance: Efficient string operations

5. _create_fallback_roadmap_data(query: str, user_context: str):
   • Purpose: Create fallback roadmap when LLM fails
   • Parameters: query (str), user_context (str)
   • Returns: Dict with basic roadmap structure
   • Work:
     - Validates inputs using SecurityValidator
     - Creates simple 3-module structure
     - Adds metadata for consistency
     - Provides safe default when LLM unavailable
   • Security: Input validation before processing
   • Reliability: Always returns valid structure

6. _create_fallback_structure(query: str):
   • Purpose: Create basic fallback structure
   • Parameters: query (str)
   • Returns: Dict with simple roadmap
   • Work:
     - Sanitizes query for safe title
     - Creates 3 modules (Fundamentals, Intermediate, Advanced)
     - Adds 2 subtopics per module
     - Provides safe learning path structure
   • Security: Input sanitization for title
   • Simplicity: Reliable structure without complexity

7. create_markmap_markdown(roadmap_data: Dict):
   • Purpose: Convert roadmap to Markmap-compatible markdown
   • Parameters: roadmap_data (Dict)
   • Returns: str (markdown format)
   • Work:
     - Extracts roadmap structure from data
     - Creates hierarchical markdown (H1, H2, lists)
     - Formats for Markmap visualization
     - Handles missing data gracefully
   • Output: Compatible with Markmap.js rendering

8. save_roadmap(roadmap_data: Dict):
   • Purpose: Save roadmap to JSON file with validation
   • Parameters: roadmap_data (Dict)
   • Returns: str (filename)
   • Work:
     - Validates roadmap data structure
     - Generates safe filename from query hash
     - Saves to JSON with proper encoding
     - Implements atomic file operations
     - Logs save operations
   • Security: Filename sanitization and validation
   • Performance: Efficient file operations

9. load_roadmap(filename: str):
   • Purpose: Load existing roadmap with validation
   • Parameters: filename (str)
   • Returns: Dict (roadmap data) or None
   • Work:
     - Sanitizes filename for security
     - Validates file existence and permissions
     - Loads JSON with proper encoding
     - Validates loaded data structure
     - Logs load operations and errors
   • Security: Path validation and structure validation
   • Error Handling: Graceful failure on invalid data

10. find_existing_roadmap(query: str):
    • Purpose: Check for existing roadmap by query
    • Parameters: query (str)
    • Returns: str (filename) or None
    • Work:
      - Validates and sanitizes query
      - Generates MD5 hash for filename lookup
      - Checks file existence in roadmap directory
      - Returns filename if found
      - Logs cache hits and misses
    • Performance: Fast lookup avoids regeneration
    • Security: Input validation before file operations
