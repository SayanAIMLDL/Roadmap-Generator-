⚙️ CLASSES/METHODS:
---------------------

1. SecurityValidator:
   • Purpose: Static utility class for security operations
   • Work: Provides all security validation methods
   • Design: Stateless utility class with static methods
   • Security: No instance state, all methods are pure functions

2. SAFE_INPUT_PATTERN:
   • Purpose: Regex pattern for allowed input characters
   • Pattern: ^[a-zA-Z0-9\s\.\,\?\!\-\_\(\)\[\]\{\}\/\:\;\@\$\'\"]+$
   • Work: Allows letters, numbers, spaces, and safe punctuation
   • Security: Blocks dangerous characters and control sequences

3. MAX_LENGTHS:
   • MAX_QUERY_LENGTH: 1000 characters for user queries
   • MAX_CONTEXT_LENGTH: 2000 characters for user context
   • MAX_TOPIC_LENGTH: 200 characters for topic names
   • Purpose: Prevents buffer overflow and DoS attacks

4. DANGEROUS_PATTERNS:
   • XSS Prevention: <script[^>]*>.*?</script>
   • JavaScript URLs: javascript:
   • Event Handlers: on\w+\s*=
   • Code Execution: eval\s*\(
   • Command Execution: exec\s*\(
   • Purpose: Blocks common attack vectors

5. validate_query(cls, query: str):
   • Purpose: Validate and sanitize user queries
   • Parameters: query (str)
   • Returns: str (sanitized query)
   • Work:
     - Type checking and null validation
     - Length limit enforcement with truncation
     - HTML escaping for XSS prevention
     - Dangerous pattern removal using regex
     - Control character removal
     - Whitespace trimming and validation
   • Security: Multi-layer input sanitization
   • Performance: Efficient string operations

6. validate_context(cls, context: str):
   • Purpose: Validate and sanitize user context
   • Parameters: context (str)
   • Returns: str (sanitized context)
   • Work:
     - Returns empty string for null/empty input
     - Applies length limits and truncation
     - HTML escaping and pattern filtering
     - Control character removal
     - Safe whitespace handling
   • Security: Context-aware validation
   • Performance: Early return for empty inputs

7. validate_topic(cls, topic: str):
   • Purpose: Validate and sanitize topic names
   • Parameters: topic (str)
   • Returns: str (sanitized topic)
   • Work:
     - Empty string validation with error raising
     - Length limit enforcement
     - HTML escaping and dangerous pattern removal
     - Control character filtering
     - Whitespace normalization
   • Security: Strict validation for critical identifiers
   • Error Handling: Raises ValueError for invalid inputs

8. validate_url(cls, url: str):
   • Purpose: Validate URLs for security and format
   • Parameters: url (str)
   • Returns: bool (valid/invalid)
   • Work:
     - URL parsing using urllib.parse
     - Scheme validation (http/https only)
     - Dangerous protocol detection (javascript, data, vbscript)
     - Returns False for invalid or dangerous URLs
   • Security: Comprehensive URL validation
   • Protection: Prevents XSS and injection via URLs

9. validate_json_structure(cls, data: Dict, required_keys: List[str]):
   • Purpose: Validate JSON structure and required fields
   • Parameters: data (Dict), required_keys (List[str])
   • Returns: bool (valid/invalid)
   • Work:
     - Type checking for dictionary structure
     - Required key presence validation
     - Returns True only if all required keys exist
     - Used for validating API responses and cached data
   • Security: Structure validation before processing
   • Integrity: Ensures data completeness

10. sanitize_filename(cls, filename: str):
    • Purpose: Sanitize filenames for secure file operations
    • Parameters: filename (str)
    • Returns: str (sanitized filename)
    • Work:
      - Path traversal prevention (removes ..)
      - Directory separator removal (/ and \)
      - Dangerous character filtering
      - Length limit enforcement (255 chars)
      - Whitespace trimming
    • Security: Path traversal attack prevention
    • File Safety: Safe filename generation

11. sanitize_input(cls, text: str, max_length: Optional[int] = None):
    • Purpose: General input sanitization utility
    • Parameters: text (str), max_length (int, optional)
    • Returns: str (sanitized text)
    • Work:
      - Type checking and null handling
      - Length limit application if specified
      - HTML escaping for XSS prevention
      - Dangerous pattern removal
      - Control character removal
      - Whitespace normalization
    • Security: Comprehensive sanitization pipeline
    • Flexibility: Configurable length limits

12. RateLimiter:
    • Purpose: Token bucket rate limiting algorithm
    • Work: Implements rate limiting with automatic cleanup
    • Design: Stateful rate limiting with time windows

13. RateLimiter.__init__(max_requests: int, time_window: int):
    • Purpose: Initialize rate limiter with configuration
    • Parameters: max_requests (int), time_window (int)
    • Returns: RateLimiter instance
    • Work:
      - Stores rate limiting parameters
      - Initializes request tracking list
      - Configures time-based cleanup
    • Security: Configurable rate limits
    • Performance: Efficient request tracking

14. RateLimiter.is_allowed(cls):
    • Purpose: Check if request is allowed under rate limits
    • Parameters: None (uses instance state)
    • Returns: bool (allowed/blocked)
    • Work:
      - Removes old requests outside time window
      - Checks current request count against limit
      - Adds new request timestamp if allowed
      - Returns False if rate limit exceeded
    • Security: Enforces rate limits
    • Performance: O(n) cleanup operation

15. RateLimiter.get_wait_time(cls):
    • Purpose: Calculate wait time for next allowed request
    • Parameters: None (uses instance state)
    • Returns: float (seconds to wait)
    • Work:
      - Finds oldest request timestamp
      - Calculates remaining time in window
      - Returns precise wait time
    • User Experience: Accurate rate limit feedback
