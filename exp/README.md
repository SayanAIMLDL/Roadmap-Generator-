# 🚀 Shifu AI - Learning Roadmap Generator

## **Quick Start**

```bash
# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

## **Main Files**

- `app.py` - Main Streamlit application
- `rag_engine.py` - RAG functionality  
- `roadmap_generator.py` - Roadmap generation
- `content_generator.py` - Content curation
- `roadmap_ui.py` - UI components
- `config.py` - Configuration management
- `security.py` - Security utilities
- `logger_config.py` - Logging system
- `api_client.py` - API client
- `reporting.py` - Analytics

## **Features**

- ✅ Secure API key management
- ✅ Input validation & sanitization  
- ✅ Rate limiting & error handling
- ✅ Optimized performance
- ✅ Structured logging
- ✅ Enterprise-grade security
