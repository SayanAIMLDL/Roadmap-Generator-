⚙️ CONFIG.PY - SECURE CONFIGURATION MANAGEMENT
===========================================

📚 LIBRARIES/MODULES USED:
---------------------------
• os - Environment variable access and file system operations
• typing - Type hints (Optional)
• dotenv - Environment file loading (.env files)
• logging - Python logging framework

🏗️ ARCHITECTURE & PURPOSE:
----------------------------
Centralized configuration management system providing:
• Secure environment variable handling
• Required key validation with fail-fast behavior
• Type-safe configuration access with defaults
• Comprehensive error handling and logging
• Production-ready configuration management
• Environment-specific settings support

⚙️ CLASSES/METHODS:
---------------------

1. Config:
   • Purpose: Centralized configuration management
   • Design: Singleton pattern with lazy loading
   • Work: Provides secure access to all configuration values
   • Security: Validates required keys at initialization
   • Performance: Lazy loading with caching

2. __init__(self):
   • Purpose: Initialize configuration with validation
   • Parameters: None
   • Returns: Config instance
   • Work:
     - Loads environment variables from .env file
     - Validates all required configuration keys
     - Raises ValueError for missing required keys
     - Logs initialization status
     - Sets up secure configuration state
   • Security: Fail-fast on missing critical configuration
   • Error Handling: Immediate feedback on configuration issues

3. _validate_required_keys(self):
   • Purpose: Validate that all required environment variables are present
   • Parameters: None (uses instance state)
   • Returns: None (raises ValueError on failure)
   • Work:
     - Defines list of required configuration keys
     - Checks each key using os.getenv()
     - Raises descriptive error for missing keys
     - Provides immediate feedback on configuration issues
   • Security: Ensures no undefined configuration values
   • Production: Prevents runtime failures from missing config

4. groq_api_key (property):
   • Purpose: Secure access to Groq API key
   • Returns: str (API key)
   • Work:
     - Retrieves API key from environment
     - Validates presence with descriptive error
     - Raises ValueError if key is missing
     - Returns key for secure LLM initialization
   • Security: API key from environment, never hardcoded
   • Error Handling: Clear error messages for missing keys

5. rapidapi_key (property):
   • Purpose: Access to RapidAPI key (optional)
   • Returns: str or None
   • Work:
     - Retrieves optional API key from environment
     - Returns None if not configured
     - Allows graceful degradation if missing
   • Flexibility: Optional configuration for enhanced features
   • Security: Environment-based key management

6. youtube_api_key (property):
   • Purpose: Access to YouTube API key (optional)
   • Returns: str or None
   • Work:
     - Retrieves optional YouTube API key
     - Returns None if not configured
     - Supports video content integration
   • Optional: Non-critical for basic functionality
   • Security: Secure optional key handling

7. groq_model (property):
   • Purpose: LLM model configuration
   • Returns: str (model name)
   • Work:
     - Retrieves model name from environment
     - Provides secure default if not specified
     - Returns configured model for LLM initialization
   • Default: meta-llama/llama-4-scout-17b-16e-instruct
   • Flexibility: Configurable model selection

8. knowledge_base_file (property):
   • Purpose: Knowledge base file path configuration
   • Returns: str (file path)
   • Work:
     - Retrieves file path from environment
     - Provides secure default if not specified
     - Returns path for knowledge base loading
   • Default: knowledge_base.txt
   • Security: Path validation and safe defaults

9. vector_db_path (property):
   • Purpose: Vector database storage path
   • Returns: str (directory path)
   • Work:
     - Retrieves vector store path from environment
     - Provides secure default if not specified
     - Returns path for FAISS index storage
   • Default: faiss_index_hf
   • Security: Path validation and safe defaults

10. roadmap_data_dir (property):
    • Purpose: Roadmap data directory configuration
    • Returns: str (directory path)
    • Work:
      - Retrieves data directory from environment
      - Provides secure default if not specified
      - Returns path for roadmap storage
    • Default: roadmap_data
    • Security: Path validation and safe defaults

11. log_level (property):
    • Purpose: Logging level configuration
    • Returns: str (log level)
    • Work:
      - Retrieves log level from environment
      - Provides secure default if not specified
      - Returns level for logger configuration
    • Default: INFO
    • Options: DEBUG, INFO, WARNING, ERROR, CRITICAL

12. max_retries (property):
    • Purpose: Maximum retry attempts for API calls
    • Returns: int (retry count)
    • Work:
      - Retrieves retry count from environment
      - Provides secure default if not specified
      - Returns count for retry logic
    • Default: 3
    • Performance: Configurable retry behavior

13. rate_limit_delay (property):
    • Purpose: Rate limiting delay configuration
    • Returns: float (delay in seconds)
    • Work:
      - Retrieves delay from environment
      - Provides secure default if not specified
      - Returns delay for rate limiting
    • Default: 1.0
    • Performance: Configurable rate limiting

14. request_timeout (property):
    • Purpose: Request timeout configuration
    • Returns: int (timeout in seconds)
    • Work:
      - Retrieves timeout from environment
      - Provides secure default if not specified
      - Returns timeout for API calls
    • Default: 30
    • Performance: Configurable timeout behavior
